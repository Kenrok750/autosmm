# Автономный агент для создания Reels через Gemini и Google Vids

Этот проект — **Фабрика Контента** с участием человека (Human-in-the-Loop). Он автоматизирует процесс создания вирусных коротких видео:
1. Заходит на страницу продавца Wildberries и парсит ссылки на товары.
2. Просит Gemini проанализировать тренды TikTok/Reels и создать визуальный сценарий.
3. Идет в Google Vids для генерации видео по сценарию.
4. Отправляет готовое видео обратно в Gemini для строгой оценки (цепляет ли хук, понятно ли видео).
5. **Останавливается и ждет вашего решения**: вы можете принять видео ("ОК, берем это!") или отправить его на доработку с учетом правок от Gemini ("Переделать").

## Установка

Вам понадобится установленный Python 3.8 или новее.

```bash
pip install -r requirements.txt
playwright install chromium
```

## Запуск Web UI (Streamlit) 🌟
Самый удобный способ работы с агентом — интерактивный дашборд.

1. Запустите сервер:
```bash
streamlit run app.py
```
2. Если вы запускаете агента впервые, в левом меню нажмите кнопку **"Запустить авторизацию (терминал)"**. Введите данные от Google, закройте вкладки капч и нажмите **Enter** в терминале.
3. **Сбор товаров:** Введите ссылку на ваш магазин (например, `seller/444343`), нажмите "Спарсить товары".
4. Выберите нужный товар из списка и начните генерацию.
5. После создания каждого видео система предложит вам оценить его. Вы полностью контролируете процесс!

## Запуск в консоли
Если вам нужен полностью автоматический режим (без ручного подтверждения):
```bash
python -m agent.main --url "https://www.wildberries.ru/catalog/..." --iterations 3 --min-score 8.5
```

## Безопасность и `state.json`
**ОЧЕНЬ ВАЖНО:** Файл `state.json` хранит вашу авторизацию Google. Не передавайте его никому.

## Структура запусков (`runs/`)
Каждый запуск создает уникальную папку в `runs/`.
Внутри:
- `input.json` — исходный URL.
- `run_state.json` — полное состояние (статус, оценки, все шаги).
- `videos/` — все сгенерированные видео.
- `prompts/` — все промпты.
- `evaluations/` — детальные оценки от Gemini.
- `screenshots/` — скриншоты в случае ошибок Playwright.

## Конфигурация (`.env`)
Создайте файл `.env` в корне проекта для изменения настроек по умолчанию:
- `MAX_ITERATIONS` (по умолчанию: 5)
- `HEADLESS` (по умолчанию: false — показывает браузер)
- `STATE_FILE` (по умолчанию: state.json)
- `OUTPUT_DIR` (по умолчанию: runs)
- `MIN_ACCEPTABLE_SCORE` (по умолчанию: 8.0)
