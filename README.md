# Автономный агент для создания Reels через Gemini и Google Vids

Этот проект представляет собой автоматизированного агента на основе Python и Playwright. Он имитирует действия пользователя в браузере:
1. Заходит в веб-интерфейс Gemini.
2. Просит создать сценарий для Reels (например, для товара с Wildberries).
3. Идет в Google Vids (используя аккаунт Google Workspace), вставляет сценарий и генерирует видео.
4. Скачивает видео, загружает его обратно в Gemini для оценки.
5. Получает правки, генерирует новое видео.
6. Повторяет цикл до 5 раз, после чего предлагает вам выбрать результат или продолжить.

## Безопасность и `state.json`
**ОЧЕНЬ ВАЖНО:** После выполнения авторизации в файле `state.json` сохраняется сессия вашего аккаунта Google (cookies и local storage).
- **Никогда не коммитьте этот файл в систему контроля версий (он уже добавлен в `.gitignore`).**
- **Не передавайте его третьим лицам.**

## Структура запусков (`runs/`)
Каждый запуск скрипта `main.py` создает новую папку в директории `runs/` (например, `runs/20231027_153000_url_slug/`).
Внутри этой папки вы найдете:
- `input.json` — исходный URL.
- `run_state.json` — полное состояние запуска (все итерации, промпты, оценки).
- `videos/` — все сгенерированные видео.
- `prompts/` — все извлеченные промпты в формате JSON.
- `evaluations/` — детальные оценки от Gemini в формате JSON.
- `screenshots/` — скриншоты в случае ошибок Playwright.

## Установка и запуск (для локального использования)

Поскольку скрипту нужен доступ к вашим аккаунтам (Gemini Advanced и Google Workspace для Vids), он предназначен для запуска **на вашем личном компьютере**.

### 1. Подготовка окружения
Вам понадобится установленный Python 3.8 или новее.

Откройте терминал (командную строку) и установите зависимости:
```bash
pip install -r requirements.txt
```

Затем установите браузеры для Playwright:
```bash
playwright install chromium
```

### 2. Первый запуск (Авторизация)
При первом запуске скрипту нужно сохранить вашу сессию (cookies), чтобы не вводить пароль каждый раз.

Запустите модуль авторизации:
```bash
python -m agent.auth
```
Откроется окно браузера. **Ваша задача:**
1. Войти в свой аккаунт Google.
2. Пройти все проверки и капчи.
3. Убедиться, что вы залогинены и видите главную страницу Google (или Gemini/Vids).
4. Закрыть окно браузера крестиком.

После закрытия окна сессия сохранится в файле `state.json`.

### 3. Конфигурация (Опционально)
Вы можете изменить поведение агента с помощью переменных окружения (или создав файл `.env`):
- `MAX_ITERATIONS` (по умолчанию: 5)
- `HEADLESS` (по умолчанию: false — запуск с видимым интерфейсом браузера)
- `STATE_FILE` (по умолчанию: state.json)
- `OUTPUT_DIR` (по умолчанию: runs)
- `MIN_ACCEPTABLE_SCORE` (по умолчанию: 8.0 — минимальная оценка от Gemini для остановки цикла)

### 4. Запуск агента
Когда авторизация пройдена, запустите основного агента:
```bash
python -m agent.main
```

Скрипт начнет работу в автоматическом режиме. Следите за логами в консоли.

### 5. Запуск тестов
Чтобы убедиться, что парсинг JSON из ответов Gemini работает корректно, запустите тесты:
```bash
python -m pytest tests -v
```

---

**Внимание:** Так как веб-интерфейсы Gemini и Google Vids часто обновляются (меняются классы кнопок и структура страниц), селекторы в коде (`page.click('селектор')`) могут потребовать ручной корректировки, если скрипт перестанет находить нужные элементы.
