# Автономный агент для создания Reels через Gemini и Google Vids

Этот проект представляет собой автоматизированного агента на основе Python и Playwright. Он имитирует действия пользователя в браузере:
1. Заходит в веб-интерфейс Gemini.
2. Просит создать сценарий для Reels (например, для товара с Wildberries).
3. Идет в Google Vids (используя аккаунт Google Workspace), вставляет сценарий и генерирует видео.
4. Скачивает видео (скрипт проверяет, что видео успешно скачалось и его размер больше 1 КБ), загружает его обратно в Gemini для оценки.
5. Получает правки, генерирует новое видео.
6. Повторяет цикл до заданного лимита итераций (или до достижения желаемой оценки от Gemini).
*Примечание: скрипт дожидается именно нового, полностью сгенерированного ответа от Gemini перед продолжением.*

## Безопасность и `state.json`
**ОЧЕНЬ ВАЖНО:** После выполнения авторизации в файле `state.json` сохраняется сессия вашего аккаунта Google (cookies и local storage).
- **Никогда не коммитьте этот файл в систему контроля версий (он уже добавлен в `.gitignore`).**
- **Не передавайте его третьим лицам.**
- **Никогда не коммитьте папку `__pycache__`**.

## Установка

Вам понадобится установленный Python 3.8 или новее.

Откройте терминал (командную строку) и установите зависимости:
```bash
pip install -r requirements.txt
playwright install chromium
```

## Как использовать агента

У вас есть три способа запустить агента: через удобный Web-интерфейс, интерактивно в консоли, или полностью скриптом.

### Способ 1: Запуск через Web UI (Streamlit) - Рекомендуется! 🌟
Самый удобный способ работы с агентом — это красивый дашборд прямо в вашем браузере.

1. Запустите сервер:
```bash
streamlit run app.py
```
2. Откроется вкладка в браузере.
3. Если вы запускаете агента впервые, в боковом меню нажмите кнопку **"Запустить авторизацию в терминале"**. Вернитесь в терминал, введите данные от аккаунта Google, закройте вкладки капч, и нажмите **Enter** в терминале.
4. Вставьте ссылку на товар, настройте ползунки и нажмите **"Запустить генерацию"**.
5. Наслаждайтесь процессом: вы будете видеть оценки Gemini и сгенерированные видео в реальном времени, а также сможете просматривать историю старых запусков!

### Способ 2: Запуск в консоли (Интерактивный)
Для тех, кто предпочитает терминал:

1. Сначала пройдите авторизацию (только один раз):
```bash
python -m agent.auth
```
В браузере войдите в аккаунт, вернитесь в терминал и нажмите Enter.
2. Запустите агента:
```bash
python -m agent.main
```
Скрипт попросит ввести URL и начнет работу.

### Способ 3: Запуск в консоли (Через аргументы CLI)
Вы можете передать параметры напрямую (удобно для автоматизации):
```bash
python -m agent.main --url "https://example.com/product" --iterations 3 --min-score 8.5
```

## Структура запусков (`runs/`)
Каждый запуск создает уникальную папку в `runs/` (например, `runs/20231027_153000_url_slug_a1b2c3/`).
Внутри:
- `input.json` — исходный URL.
- `run_state.json` — полное состояние запуска (все итерации, промпты, оценки, финальный статус).
- `videos/` — все сгенерированные видео.
- `prompts/` — все извлеченные промпты (JSON).
- `evaluations/` — детальные оценки от Gemini (JSON).
- `screenshots/` — скриншоты в случае ошибок Playwright.

## Конфигурация (`.env`)
Создайте файл `.env` в корне проекта (он игнорируется git) и укажите нужные значения по умолчанию:
- `MAX_ITERATIONS` (по умолчанию: 5)
- `HEADLESS` (по умолчанию: false — запуск с видимым интерфейсом браузера)
- `STATE_FILE` (по умолчанию: state.json)
- `OUTPUT_DIR` (по умолчанию: runs)
- `MIN_ACCEPTABLE_SCORE` (по умолчанию: 8.0)

## Запуск тестов
Чтобы убедиться, что парсинг JSON работает корректно:
```bash
python -m pytest tests -v
```

## Решение проблем

**Ошибка: Неполный или невалидный JSON от Gemini**
Скрипт использует регулярные выражения, чтобы извлечь JSON из ответа. Если парсинг провалится, в консоли/веб-интерфейсе появится ошибка, будет сделан скриншот в `screenshots`, а текущий запуск получит статус `failed`.

**Селекторы Google Vids:**
Так как веб-интерфейсы часто обновляются, селекторы в `agent/vids.py` могут потребовать ручной корректировки.
